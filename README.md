# 共通テスト 一問一答

大学入学共通テストの対策を、スマホで1問数秒ずつ進めるためのアプリです。
HTMLファイル1つで動きます。インストールやアカウント登録はいりません。

## 使い方

`index.html` をスマホのブラウザで開きます（GitHub Pages などに置くと、URLを開くだけで使えます）。
ホーム画面に追加すると、アプリと同じように起動でき、電波のない場所でも学習できます。

- **4択テスト**：選択肢から正解を選びます。答えると、正解と一言の解説が出ます。
- **一問一答**：答えを思い浮かべてから「答えを見る」で確かめ、「わかった／まだ」を自分で付けます。
- 科目・出題年度（2022〜2026）・1回の問題数で範囲を絞れます。「苦手だけ」にもできます。
- 苦手な問題（直近で不正解）→ 復習時期の問題 → まだ出ていない問題 の順に優先して出します。
- 「問題一覧」で、科目ごとに問題と答えを検索・確認できます。

## 収録している問題（812問）

2022〜2026年度の共通テスト本試験で問われた事項を、予備校の分析・解説（東進、河合塾、Z会など）で調べ、
それをもとに作った**オリジナルの一問一答**です。過去問の文や選択肢をそのまま使ってはいません。
計算・グラフの読み取り・長文読解は入れていません。

### 根拠の確かさについて
- 各問の「出題年度」は、その事項（またはその事項を含む大問のテーマ）が出た年度です。
- 日本史・世界史・倫理・政治・経済は、設問ごとの解説で確認できた事項から作っています。
- 地理・生物・地学（地学基礎を除く）・英語の語彙・漢文の基本句法などは、大問のテーマまでは確認済みで、
  その中の基本事項を問題にしたものを含みます（その語句そのものが設問になったとは限りません）。
- 物理と数学は計算が中心なので入れていません。

## 学習記録の保存

記録は使っている端末のブラウザの中だけに保存されます。別の端末とは共有されず、
ブラウザのサイトデータを消すと記録も消えます。

## ファイル構成

```
index.html             アプリ本体（問題データ込み。build.py が作る）
manifest.webmanifest   ホーム画面に追加したときの名前・アイコン
sw.js                  オフラインで使えるようにするしくみ
icons/                 アイコン（src/icons.py で作成）
data/*.txt             科目ごとの問題データ
src/template.html      画面のもと
src/build.py           data/ を検査して template に差し込み index.html を作る
```

## 問題を追加・修正するには

`data/<科目>.txt` に1行1問で書き、`python src/build.py` を実行します。

```
分野|問題|正解|誤答1|誤答2|誤答3|出題年度|解説
近代|1872年に公布された近代的学校制度の法令は？|学制|教育令|学校令|教育勅語|2023|国民皆学をめざした
```

- 出題年度は `2022`〜`2026`。複数なら `2022,2025`。
- 選択肢が重複している行・列数が違う行は、build.py が警告を出して取り込みません。
- 問題文を変えると、その問題の学習記録はリセットされます（問題文から番号を作っているため）。
